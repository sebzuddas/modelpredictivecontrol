# Landing Page Content - Model Predictive Control Education

This document outlines the educational content and external resources provided on the static site's landing page (`templates/index.html`). The goal is to introduce users to Model Predictive Control (MPC) and provide avenues for further learning.

## Educational Content

The landing page will include an overview of Model Predictive Control, covering the following key aspects:

1.  **What is MPC?**
    *   Brief definition and core concept (predictive model, optimization, receding horizon).
    *   Why is it used (handling constraints, multi-variable systems, optimal control).
2.  **Key Components of MPC:**
    *   **Prediction Model:** How it forecasts future system behavior.
    *   **Cost Function (Objective Function):** What it minimizes (e.g., control effort, tracking error).
    *   **Constraints:** How it handles operational limits (e.g., actuator limits, safety zones).
    *   **Optimizer:** The role of solving an optimization problem.
    *   **Receding Horizon Principle:** The iterative nature of MPC.
3.  **Benefits of MPC:**
    *   Optimal control in complex scenarios.
    *   Ability to handle disturbances and uncertainties.
    *   Constraint satisfaction.
    *   Applications (e.g., aerospace, automotive, process control).
